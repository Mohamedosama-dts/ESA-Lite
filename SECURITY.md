# Security Policy

## Supported versions

Security fixes are accepted for the latest published **ESA-Lite** release line on the default branch.

## Reporting a vulnerability

Please report security issues **privately** via GitHub Security Advisories on this repository (**Security → Report a vulnerability**). Do not file a public GitHub issue for undisclosed vulnerabilities.

Include:

- ESA-Lite version (or commit SHA)
- OS version and token/vendor if relevant
- Steps to reproduce and impact assessment

We will acknowledge receipt and coordinate a fix and disclosure timeline.

## Scope notes

ESA-Lite is a **local** Windows token display and management tool. It does not implement remote hash-signing or a server bus. Reports about commercial agent signing protocols are out of scope for this repository.
